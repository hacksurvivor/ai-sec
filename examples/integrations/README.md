# AI Coding CLI Integrations

This folder provides installation templates for agent-first usage.

- Claude Code: `examples/integrations/claude`
- Codex CLI: `examples/integrations/codex`

## Quick start

```bash
# Claude Code native hooks
bash ./examples/integrations/claude/install.sh

# Codex guarded wrapper
bash ./examples/integrations/codex/install.sh
```
